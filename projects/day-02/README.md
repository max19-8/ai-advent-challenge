# День 2. Формат ответа

Один вопрос, пять вариантов по три повтора — **15 запросов** к DeepSeek V4 Flash
через Polza.ai. Провайдер — `streamlake/fp8`, рассуждения отключены.

> Расскажи о планете Марс: укажи её порядковый номер от Солнца,
> назови естественные спутники и кратко опиши поверхность.

## Запуск

Из корня репозитория с ключом `POLZA_API_KEY` в общем `.env`:

```bash
source .venv/bin/activate
python -m pip install -r requirements.txt
python projects/day-02/main.py
```

Ответы и параметры сохраняются в `results.json` после каждого запроса.
Новый запуск заменяет файл. HTTP-таймаут и автоматические повторы не заданы.

## Результаты и выводы

Прогон 2026-11-07 20:48:36 UTC: получены все 15 ответов без ошибок API.
Полные запросы и ответы — в [results.json](results.json).

| Вариант | Выходные токены по повторам | Наблюдение |
| --- | --- | --- |
| Обычный ответ | 268, 276, 317 | Модель сама выбрала списки, Markdown и объём; все части вопроса раскрыты |
| Формат словами | 102, 91, 81 | Инструкция вернуть JSON сработала 3/3 раза |
| Только max_tokens=50 | 50, 50, 50 | Все ответы оборвались посреди текста, `finish_reason=length` |
| Stop sequence | 20, 20, 20 | Осталась только фраза «Марс — четвёртая планета от Солнца.» |
| Строгая JSON Schema | 155, 177, 144 | API принял схему; все три объекта соответствуют полям и типам |

**Инструкция формата** управляет оформлением через текст запроса.
**JSON Schema** задаёт структуру через параметр API: `planet` и `surface` — строки,
`position` — целое число, `satellites` — массив строк; все поля обязательны,
лишние запрещены. Все шесть JSON-ответов прошли `json.loads` и проверку схемы
без исправлений. В этой выборке оба способа дали 3/3, преимуществ по частоте
успешного разбора не обнаружено. Структура не гарантирует правильность фактов.

**max_tokens** ограничил генерацию, но не заставил модель спланировать короткий
законченный ответ: часть запрошенных сведений потерялась.
**Stop** задавался как `stop=["<<<END>>>"]`. В инструкции маркер стоял после номера
планеты, перед спутниками и описанием поверхности. Ни маркер, ни продолжение
не вернулись — результат соответствует остановке на выбранной границе.
Отдельного подтверждения причины остановки и контрольного запроса без stop нет.

JSON проверяем только там, где его запросили. Для обычного ответа, лимита и stop
оцениваем содержание и завершённость. Три повтора одного вопроса характеризуют
этот прогон, а не надёжность модели на любых задачах.

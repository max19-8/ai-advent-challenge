# День 17. Первый собственный инструмент MCP

Агент отвечает на вопросы о статусе и исполнителе задачи. Единственный
инструмент, `get_issue`, предоставляет наш MCP-сервер. Данные принадлежат
учебному HTTP API трекера.

## Запуск

Потребуются Python 3.10+ и `POLZA_API_KEY` в окружении или корневом файле
`.env`. Из корня репозитория при первой установке:

```bash
python3.12 -m venv projects/day-17/.venv
projects/day-17/.venv/bin/python -m pip install -r projects/day-17/requirements.txt
```

Одна команда запускает агента, сервер и два независимых диалога:

```bash
projects/day-17/.venv/bin/python -u projects/day-17/main.py 2>&1 | tee /tmp/day-17-mcp.log
```

## Как работает

1. **Регистрация.** В `server.py` декоратор `@mcp.tool()` регистрирует
   Python-функцию `get_issue`. Из имени, документации и аннотаций SDK получает
   описание и схему. Обязательный параметр `issue_id` — строка вида `DEMO-17`.
2. **Обнаружение.** Приложение запускает сервер дочерним процессом, открывает
   сессию через stdio и вызывает `initialize()` и `list_tools()`. В запрос к
   модели попадают имя, описание и `inputSchema` инструмента в поле
   `function.parameters`. В `messages` находятся инструкция и вопрос пользователя.
3. **Выбор и вызов.** Если модель возвращает `tool_calls`, цикл агента из
   Дня 6 читает имя и аргументы. Например, для задачи DEMO-17 приложение
   разбирает строку JSON в словарь и вызывает
   `session.call_tool("get_issue", {"issue_id": "DEMO-17"})`.
4. **Выполнение на сервере.** MCP SDK проверяет аргументы и вызывает
   `get_issue(issue_id="DEMO-17")`. Функция отправляет HTTP-запрос
   `GET /issues/DEMO-17`. Запрос обрабатывает маршрут Starlette через
   `httpx.ASGITransport` внутри серверного процесса. Поэтому отдельный
   сетевой порт учебному API не нужен. При HTTP 200 сервер возвращает
   идентификатор, статус и исполнителя. При HTTP 404 возвращает идентификатор
   и сообщение об отсутствии задачи.
5. **Использование результата.** Приложение берёт структурированный ответ
   MCP-сервера и добавляет его в историю с ролью `tool` и идентификатором
   исходного вызова. Python отправляет обновлённую историю модели. По её
   финальному ответу можно проверить, какие данные она использовала.

## Результаты проверки

В локальной проверке ответ с вызовом инструмента был задан тестом. Агент
прошёл обычный цикл выполнения через настоящую MCP-сессию до формирования
следующего сообщения для модели. Проверены содержимое сообщения и его
привязка к вызову через `tool_call_id`.

| Аргумент | Ответ HTTP API | Данные, переданные агентом в историю |
| --- | --- | --- |
| DEMO-17 | 200 | Статус «На проверке», исполнитель Анна Соколова |
| DEMO-404 | 404 | Идентификатор DEMO-404 и сообщение «Задача не найдена» |

### Живой прогон 25 ноября 2026 года

Для контрольного сценария в учебном трекере намеренно отсутствует DEMO-404.
Так проверяем, сообщит ли агент об отсутствии задачи и какие данные попадут в ответ.

В двух независимых диалогах модель `deepseek/deepseek-v4-flash` получила
вопрос пользователя и схему `get_issue` с обязательной строкой `issue_id`.
В обоих случаях при `tool_choice: "auto"` модель сама запросила инструмент
и взяла ключ задачи из вопроса.

| Что запросила модель | Что произошло на сервере | Как модель использовала результат |
| --- | --- | --- |
| `get_issue({"issue_id":"DEMO-17"})` | `GET /issues/DEMO-17` вернул HTTP 200 | Ответила, что задача «На проверке» и за неё отвечает Анна Соколова. Оба поля совпали с карточкой. |
| `get_issue({"issue_id":"DEMO-404"})` | `GET /issues/DEMO-404` вернул HTTP 404 | Сообщила, что задача не найдена, и предложила проверить ключ. Неверный ключ был предположением модели. Трекер сообщил только об отсутствии задачи. |

Каждый диалог потребовал двух обращений к модели и одного вызова нашего
MCP-инструмента. В теле второго запроса видно сообщение с ролью `tool`:
его `tool_call_id` совпадает с идентификатором из первого ответа модели,
а `content` содержит JSON трекера. Получив эти данные, модель в обоих
случаях завершила диалог с причиной `stop`. HTTP 404 вернулся агенту как
результат поиска, поэтому отсутствующая задача тоже получила финальный ответ.

# День 4. Температура

Три задачи × `temperature=0`, `0.7`, `1.2` × пять повторов — **45 запросов**.
Модель — `deepseek/deepseek-v4-flash`, провайдер — `streamlake/fp8`, без переключений.
Рассуждения отключены. Лимит токенов и HTTP-таймаут не задаются, повторных попыток нет.
Меняется только температура. Каждый запрос независимый, без истории и системного промпта.

| Задача | Что проверяем |
| --- | --- |
| Рыцари и лжецы | Правильность итогов и объяснений; разнообразие формулировок |
| Названия приложения привычек, свободный ответ | Повторяемость, разнообразие и полезность идей |
| Три названия по шаблону `1. название`, `2. название`, `3. название` | Соблюдение текстовой инструкции о формате |

Полные вопросы — в `TASKS` в `main.py`. Локальный эталон логической задачи:
Борис — рыцарь, Анна, Вера и Глеб — лжецы. Единственность проверена перебором
16 назначений типов. Эталон модели не передаётся.

В свободном творческом запросе не ограничиваем язык, количество и длину названий.
В отдельном запросе на формат нужны ровно три строки с номерами `1.`, `2.`, `3.`
и непустыми названиями, без текста до и после списка. Краевые пробелы и переносы
не учитываем; пустая строка внутри списка нарушает формат. Проверка оформления
не определяет качество названий и не запрещает смысловые повторы. JSON не запрашивается.

## Запуск

Из корня рабочей копии с общим ключом `POLZA_API_KEY` в `.env`:

```bash
source .venv/bin/activate
python projects/day-04/main.py
```

Порядок: повтор → задача → температура 0, 0.7, 1.2; всего пять раундов.
Ответы печатаются в терминале и сохраняются обычным текстом в `results.txt`,
с группировкой по задаче и температуре. Файл обновляется до и после обращения.
Ошибка API останавливает прогон, обрезанный ответ сохраняется, Ctrl+C сохраняет
частичные результаты. Следующий запуск заменяет файл.

Автоматически считаются полученные ответы, обрезание, уникальные полные тексты
и нарушения формата только для третьего запроса. Полнота здесь означает
`finish_reason=stop` и непустой текст, а не доказанную правильность или полноту содержания.
Посимвольное сравнение учитывает пробелы и оформление исходных ответов.
Обрезание может само вызвать нарушение формата; эти показатели не складываем как разные ошибки.

## Результаты

Получены все **45 ответов**, каждый завершён с `stop`. Ошибок API и обрезания нет;
reasoning-токены во всех ответах — 0. Итоги логической задачи проверены вручную:
во всех ответах Борис — рыцарь, Анна, Вера и Глеб — лжецы.

| Температура | Верных итогов логической задачи | Уникальных текстов решения | Уникальных свободных творческих ответов | Уникальных списков по шаблону | Нарушений формата |
| --- | --- | --- | --- | --- | --- |
| 0 | 5/5 | 5/5 | 5/5 | 3/5 | 0/5 |
| 0.7 | 5/5 | 5/5 | 5/5 | 5/5 | 0/5 |
| 1.2 | 5/5 | 5/5 | 5/5 | 5/5 | 0/5 |

Различие полного текста ещё не означает новый набор идей. Поэтому отдельно
посчитаны названия: регистр не учитывается, краевые пробелы удаляются,
последовательности пробельных символов заменяются одним пробелом. Смысловые
совпадения и слитное/раздельное написание не объединяются.

| Температура | Уникальных названий / всего в основных свободных списках | Доля уникальных | Уникальных названий / всего в списках по шаблону |
| --- | --- | --- | --- |
| 0 | 138/173 | 79,8% | 5/15 |
| 0.7 | 124/170 | 72,9% | 13/15 |
| 1.2 | 126/127 | 99,2% | 14/15 |

Это дополнительный разбор сохранённых ответов, не встроенная оценка скрипта.
В свободной генерации считались основные перечни названий; советы, повторные
рекомендации фаворитов и варианты внутри заключительной прозы исключены.
Количество названий не задавалось, поэтому модель предложила разные объёмы.

## Примеры и выводы

**Температура 0 не обеспечила одинаковый текст.** Логическая задача во всех
пяти повторах получила верный итог, но объяснения отличались. В свободных названиях
тоже пять разных ответов. При этом отдельные идеи повторяются: `Momentum` —
в четырёх свободных ответах, `Якорь` и `Loop` — в трёх.

В задании на формат при 0 совпали ответы 1 и 4, а также 2 и 3. Например,
второй и третий повторы дали один и тот же список:

```text
1. Привычка+
2. Шаг вперёд
3. День за днём
```

Всего при 0 в пяти списках из трёх названий встретилось только пять уникальных
названий. Значит, низкая температура здесь усилила повторение идей, но не сделала
каждый ответ идентичным.

**При 0.7 формат и точность сохранились**, а короткие списки стали разнообразнее:
13 уникальных названий из 15. Пример второго повтора:

```text
1. Привычка.Про
2. Шаг вперёд
3. Якорь
```

В свободной генерации 0.7 не превзошла 0 по доле уникальных названий:
72,9% против 79,8%. Рост температуры не дал монотонного роста разнообразия
во всех частях эксперимента.

**При 1.2 почти исчезли повторы названий**, включая 14 уникальных названий из 15
в коротких списках. Пример пятого повтора:

```text
1. HabitPath
2. Привычка-Маяк
3. StrideDaily
```

Свободные ответы заметнее меняли стиль и язык. В третьем повторе встретились
`Progма`, `Pulse глава`, пояснение «эницкл» и фрагмент «запрограммированную пов-»
с продолжением «тор.» на следующей строке. Это ошибки текста при `stop`,
а не обрезание по лимиту токенов. Разнообразие в таком ответе требует отбора
и редактирования.

**Формат не нарушился ни при одной температуре.** Все 15 ответов на отдельный
запрос содержат ровно три пронумерованные строки. В свободном запросе дополнительные
пояснения и разное число названий допустимы, поэтому не считаются ошибками формата.
Высокая температура в этом прогоне не ухудшила итог логической задачи:
при 1.2 тоже 5/5 верных решений.

| Температура | Практическое применение по результатам эксперимента |
| --- | --- |
| 0 | Точные задачи и ответы с меньшим разбросом идей. Подходит для исходного варианта решения; буквального совпадения текстов не обеспечивает |
| 0.7 | Генерация нескольких вариантов при сохранении текстового шаблона. В коротких списках дала больше новых названий, чем 0 |
| 1.2 | Поиск необычных идей и разных стилей. Полезна для чернового набора вариантов с последующим отбором и исправлением текста |

Температура меняет вероятности выбора продолжения, а не задаёт правильность ответа.
В точной задаче разнообразие формулировок не принесло дополнительной пользы:
правильный итог один и одинаков при всех температурах. В генерации названий
разнообразие расширяет выбор, но количество новых строк не заменяет качество идей.

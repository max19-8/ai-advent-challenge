# AI Advent Challenge

Учебные задания по работе с языковыми моделями через API Polza.ai.
Код и пояснения добавляем постепенно, по мере прохождения курса.

## Подход

- Каждый день — папка `day-01`, `day-02` и так далее, с `main.py` и коротким README.
- Один `.env`, одна виртуальная среда и общие зависимости в корне.
- Запросы через `requests`, настройки через `python-dotenv`.
- Модель выбираем под задание. Новые файлы и тесты добавляем по необходимости.
- Общение и документация — на русском.

## Окружение

```bash
cd /Users/maxim.kozyrev/Projects/ai-advent-challenge
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

В корневом `.env` укажите `POLZA_API_KEY`. Файл остаётся локальным и игнорируется Git.
Для повторной настройки используйте `.env.example` как образец.
Скрипты дней будут читать этот общий файл по его пути, независимо от папки запуска.

Endpoint: `https://polza.ai/api/v1/chat/completions`.

# День 1. Первый запрос к LLM через API

Вводим вопрос в терминале, отправляем его в DeepSeek V4 Flash через Polza.ai
и выводим полученный текст. Каждый запуск — один независимый вопрос.

## Запуск

Из корня репозитория при первой настройке:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

В корневом `.env` должна быть строка `POLZA_API_KEY=твой_ключ`.
Для новой установки можно скопировать `.env.example` в `.env`.
Ключ не публикуется в Git.

```bash
source .venv/bin/activate
python day-01/main.py
```

Введи вопрос, например: «Объясни простыми словами, что такое API».

## Что происходит в коде

1. `load_dotenv` читает общий `.env`; переменные окружения имеют приоритет.
2. `input` получает вопрос пользователя.
3. `requests.post` отправляет JSON с моделью и сообщением пользователя.
   Заголовок `Authorization` содержит ключ, `reasoning.enabled=False`
   запрашивает режим без рассуждений. Остальные параметры генерации не задаются.
4. `raise_for_status` проверяет HTTP-ошибки, `response.json` разбирает ответ API.
5. Текст из `choices[0].message.content` выводится через `print`.

Соединение ожидается до 10 секунд, чтение ответа — до 120 секунд без новых данных.
Автоматических повторов нет. История диалога и файлы результатов не сохраняются.

## Видео

Покажи `main.py`, объясни состав запроса, запусти скрипт и задай вопрос.
Покажи ответ в терминале. Не открывай `.env` во время записи.
